# Contributing to DQN-Enhanced Adaptive Artificial Noise Power Allocation

Thanks for your interest in contributing!

## How to contribute

1. Fork the repository and create your branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Test your changes before submitting (run `python scripts/demo.py` to
   validate the simulation primitives).
4. Open a pull request describing what you changed and why.

## Reporting issues

- Use GitHub Issues to report bugs or request features.
- Include steps to reproduce, expected behavior, and actual behavior.

## Code style

- Python 3.10+, numpy-based; keep channel shapes `(Nt,)` complex128.
- Keep changes focused and minimal.
- Follow the existing style and conventions of the codebase.

## Questions

Open an issue if anything is unclear.
